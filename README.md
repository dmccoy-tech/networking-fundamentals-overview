# networking-fundamentals-overview

# A breakdown of core networking concepts including IP addressing, protocols, and how devices communicate.

## Overview
This project documents foundational networking concepts learned through hands-on study. It focuses on how devices communicate, how data flows across networks, and the basic structure of the internet.

## Topics Covered

### What is Networking?
Networking allows devices to communicate and share data across systems, whether locally or over the internet.

### Types of Networks
- LAN (Local Area Network)
- WAN (Wide Area Network)
- MAN (Metropolitan Area Network)

### IP Addressing
- Devices are identified using IP (Internet Protocol) addresses
- IPv4 vs IPv6
- Public vs Private IPs

### Protocols
- TCP: Reliable, connection-based communication
- UDP: Faster, connectionless communication
- HTTP/HTTPS: Web communication protocols
- DNS: Resolves domain names to IP addresses

### How Data Travels
- Data is broken into packets
- Packets move across networks using routing
- Each packet contains important information like source/destination IP
- TCP/IP (Three-Way Handshake)
- UDP/IP
- Ports

## What I Learned
- How devices communicate across networks
- The role of protocols in data transmission
- MAC addresses
- How to determine wether the IP address is public or private
- OSI Model
- Ports 101 (Ports Protocols)
- Firewalls
